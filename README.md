# 🎨 Cartoon Avatar Motion Studio

A cloud-ready, web-based studio designed to bring static cartoon character images to life. Powered by AI voice synthesis and image animation pipelines, this tool allows you to upload any character, type a script, and generate synchronized talking videos directly from your browser or mobile phone.

## ✨ Features
* **Custom Avatar Upload:** Upload any cartoon image, illustration, or AI-generated character (PNG/JPG).
* **AI Voiceover Generation:** Built-in integration with Edge-Neural voices for natural, gritty, or professional narration.
* **Mobile-Friendly UI:** Designed with Gradio so you can run, manage, and download creations straight from your phone browser.
* **Cloud Ready:** Optimized for free cloud deployment on Hugging Face Spaces.
